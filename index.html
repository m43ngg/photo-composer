레이어 (위가 앞)

    아직 붙인 사진이 없어요. “사진 추가”를 누르세요.

    선택한 사진

    사용법

    • 사진을 드래그해서 이동
    • 모서리 □ 를 끌어 크기 조절
    • 위쪽 ○ 를 끌어 회전 (Shift: 15° 단위)
    • 마우스 휠로 크기 조절
    • 방향키로 미세 이동 (Shift: 10px)
    • Delete 키로 삭제
    • 더블클릭하면 자르기 창이 열려요
    • 도형은 모서리를 끌면 가로·세로를 따로 조절해요 (Shift: 비율 유지)
    • 닉네임 가리기: 도형 추가 → 단색 / 모자이크 / 흐림
    자르기 원하는 부분을 드래그해서 선택하세요. 선택 영역 안을 끌면 이동합니다.
    100% 휠: 확대 · 스페이스/우클릭 드래그: 화면 이동 · 방향키: 1px 이동
