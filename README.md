# 사진 합성기

브라우저에서 바로 쓰는 간단한 사진 합성 도구입니다. 설치 없이 `index.html` 하나로 동작하고, 사진은 서버로 올라가지 않고 내 컴퓨터 안에서만 처리됩니다.

## 기능

- 배경 사진 위에 여러 장의 사진 붙이기 (드래그 앤 드롭, Ctrl+V 붙여넣기)
- 사진·배경 자르기 — 휠 확대, 화면 이동, 변/모서리 손잡이, 방향키 1px 이동, 비율 고정
- 이동 · 크기 · 회전 · 투명도 · 좌우 반전 · 레이어 순서 · 복제
- 모양(사각형 / 둥근 사각형 / 원), 테두리, 그림자
- 닉네임 가리기용 도형: 단색 / 모자이크 / 흐림
- 원본 해상도로 PNG · JPG 저장

## 사용법

웹에서 열거나, `index.html`을 내려받아 더블클릭하면 됩니다.

| 동작 | 방법 |
| --- | --- |
| 이동 | 드래그 / 방향키 (Shift: 10px) |
| 크기 | 모서리 □ 드래그 / 마우스 휠 |
| 회전 | 위쪽 ○ 드래그 (Shift: 15° 단위) |
| 자르기 | 더블클릭 또는 ✂ 자르기 |
| 삭제 | Delete |
